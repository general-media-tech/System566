🔑 إدارة كلمات السر

مكان واحد لكل كلمات السر — بصدق تام عن أي وحدة تنعدّل من هون وأي وحدة من Supabase

🟢 كلمات السر المخزّنة بالقاعدة — تنعدّل من هون مباشرةً

هذه محفوظة بجدول gmt_settings. أي تعديل هون يُحفظ فوراً بالقاعدة ويسري على كل الأجهزة.
تريد تضيف كلمة سر جديدة بالقاعدة؟ اكتب مفتاحها (مثل cashier_password) واسمها الظاهر ثم أضِف:

🔵 كلمات سر Supabase Auth — تُدار من لوحة Supabase

بصراحة: هذه لا تنعدّل من هون (ولا من أي صفحة). هي بنظام مصادقة Supabase نفسه، ويتغيّرها إلا من لوحة تحكّم Supabase.
👑 الأدمن السيادي
دخول عبر بريد + كلمة سر (Supabase Auth).
للتغيير: Supabase → Authentication → Users → اختر المستخدم → Reset / Update password.
🌐 أدمن الموقع
نفس نظام Supabase Auth.
لإنشاء/تغيير: Supabase → Authentication → Users → Add user (أو Update password لمستخدم موجود).

⚠️ ملاحظات أمان

• لا تشارك كلمات السر بروابط عامة.
• غيّر admin_password دورياً.
• هذه الصفحة تتّصل بالقاعدة بمفتاح anon العام (نفس باقي الصفحات) — الحماية الفعلية من صلاحيات RLS بالقاعدة.
• انشر هذه الصفحة فقط بمكان تتحكّم بالوصول إليه.
