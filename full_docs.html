📋 نظرة عامة

🎓 التعليم التفاعلي

موظف جديد يتعلّم النظام بنفسه دون شرح بشري. الجولة التفاعلية:

  1. تُأشّر على كل زر بالشاشة (حلقة حمراء نابضة).
  2. تشرح: ماذا يفعل الزر · متى تستعمله · ماذا يتغيّر عند الضغط.
  3. تنتقل للزر التالي عند الضغط على «التالي» — حتى إكمال كل الأزرار.

كيف تفتحها

من زر 🎓 بأي صفحة ← «🚶 جولة: أشّر لي على كل زر»، أو من الوضع التدريبي ← زر «📖 دليل الأزرار».

🎯 الوضع التدريبي آمن تماماً — كل ما تفعله يذهب لقاعدة وهمية، لا يمسّ بياناتك الحقيقية ولا يُرسل لأحد.

🚀 النشر والتحديث

نشر جديد

  1. شغّل ملفات SQL بالترتيب (ابدأ بملفات GMT_00_BASE_*).
  2. ارفع مجلدات النشر الـ19 كما هي.
  3. ارفع الصور واللوغوات (انظر القسم التالي).
  4. افتح صفحة كأدمن واضغط 🧪 الفاحص الذاتي للتأكد.

تحديث نظام قائم

ارفع مجلد الملفات المشتركة كاملاً فوق القديم — يحدّث كل البوتات والصفحات دفعة واحدة. لا حاجة لإعادة نشر كل شيء.
